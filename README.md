# sun-moon-toggle-ui
Interactive Sun and Moon toggle UI designed and prototyped in Figma.
## Features

- Sun mode
- Moon mode
- Clickable toggle interaction
- Smooth transition using Smart Animate

## Tools Used

- Figma
- UI/UX Design
- Prototyping
